Hardware Ingestion

ALVEON replaces expensive managed cloud databases (such as AWS RDS or Google Cloud SQL, which cost $200–$800/month) with an embedded, zero-configuration SQLite database running in Write-Ahead Logging (WAL) mode. WAL mode enables concurrent multi-threaded writes without locking read queries. All reports, caliper annotations, user accounts, and cryptographic audit logs persist directly inside data/alveon.db with industrial ACID durability and zero monthly fees.
Yes. ALVEON includes an active, native DIMSE Storage Service Class Provider (SCP) listening on TCP port 11112. Hospital radiological technicians configure ALVEON's IP address and AE Title (ALVEON_SCP) into the console of their acquisition modality. When a technician finishes an X-ray or CT acquisition, the modality performs a standard DICOM C-STORE push directly into ALVEON. The background listener validates the DICOM header and immediately triages the study in <1.2 seconds.
Under HIPAA Privacy Rule § 164.514, Protected Health Information (PHI) is scrubbed client-side across all 18 direct identifiers before any research export or external transmission. Concurrently, ALVEON computes a cryptographic SHA-256 hash over the raw pixel buffer, ensuring that image pixel values remain bit-for-bit identical to the diagnostic original while metadata is scrubbed. Furthermore, all physician interactions are logged into an immutable SHA-256 chained audit ledger satisfying 45 CFR § 164.312(b).
